# Security

## Supported versions

Only the latest commit on `main`, which is what the website serves, receives fixes.

## Report a vulnerability

Do not open a public issue. Report it privately on GitHub: in this repository, open **Security**,
then **Report a vulnerability**, and fill in the form.

Include what is affected (a page of the site, the build or the CI workflow), the steps to
reproduce it and the impact you see. You get an answer that confirms the report, and you are kept
informed until it is fixed. Once the fix is published, the report is published with credit to
you, unless you prefer otherwise.

## Scope

- **In scope:** the website and what it publishes, the build and the CI workflow, and anything in
  the repository that could leak a secret or send a visitor somewhere they did not expect.
- **Out of scope:** vulnerabilities in GitHub Pages, Google Drive, DocuSign or Astro themselves,
  which go to their own projects.
